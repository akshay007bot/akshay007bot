# VedRxTours brand Reel (9:16)

33-second 1080×1920 cinematic Reel for vedrxtours.in, built to the client brief:

1. **A new hook every ~3 seconds** – 13 voice lines, each a question, reveal or pattern interrupt, with 30+ cuts (a cut on almost every keyword).
2. **B-roll matches the words** – each shot shows exactly what is being said: waiting room → medical bill → plane wing → Taj Mahal → Apollo / Fortis / Artemis / Max → operating theatre + ECG → knee X-ray scan → chemo → IVF centre → dentist → "best part" interrupt → care coordinator → passport / flight / hotel "HANDLED" → follow-up call → flying home → personalised estimate → logo + CTA.

- **Final:** `out/vedrx-reel.mp4` (H.264, -14 LUFS)
- **Voice:** Kokoro TTS `am_onyx`, natural pitch, word-synced captions with keyword highlights
- **Score:** original, generated by `score_generator.py` from `src/timeline.json` (hits on every line, riser + drop before "best part")
- **Media credits:** `public/broll/CREDITS.txt` (Wikimedia Commons, free licences) + vedrxtours.in site images

## Re-render
```bash
npm install
npx remotion render src/index.ts VedRxReel out/vedrx-reel.mp4 --concurrency=4 --timeout=120000
```
