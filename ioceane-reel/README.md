# iOceane cinematic Reel (9:16)

35-second 1080×1920 trailer-style Reel built with Remotion.

- **Final:** `out/ioceane-reel.mp4` (H.264, -14 LUFS, ready for Instagram Reels / YouTube Shorts)
- **Storyboard:** `out/storyboard.png`
- **Voice:** Kokoro TTS `am_onyx`, pitched down ~2 semitones + bass, compression and hall reverb (`public/audio/v1–v7.wav`)
- **Score:** original synthesised trailer score — drone, pulse, braams, risers, hits — generated by `score_generator.py` from `src/timeline.json`, so every hit lands on a cut
- **Look:** god rays, fog, bokeh dust, glowing ocean-wave lines, camera push + hit shake, flashes, anamorphic streaks, light leaks, film grain, 3D logo tunnel, lens-flare logo reveal

## Re-render

```bash
npm install
npx remotion render src/index.ts IoceaneReel out/raw.mp4 --muted --concurrency=4 --timeout=120000
./mix.sh out/raw.mp4 out/ioceane-reel.mp4     # mixes score + VO (ducked) and normalises loudness
```

Cut timings, VO start frames and music hits all live in `src/timeline.json`.
